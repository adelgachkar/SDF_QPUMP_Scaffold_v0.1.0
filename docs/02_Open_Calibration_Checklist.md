# Open calibration checklist

- [ ] Define hardware/sample geometry, boundary conditions, and coordinate handedness.
- [ ] Measure cavity resonance frequency, linewidth/damping, coupling, transfer function, and uncertainty over the operating range.
- [ ] Specify amplitude normalization and whether reported values are field amplitude, energy, or detector counts.
- [ ] Fix phase origin, unwrap convention, and synchronized sampling / delay correction for top and bottom phase channels.
- [ ] Determine pump gain, saturation, deadband, sign, and force/flow output against traceable standards.
- [ ] Define Berry-curvature observable, units, estimator, gauge convention, and independent control measurement.
- [ ] Test the bridge coupling against null conditions and alternative explanations; quantify covariance with phase-rate errors.
- [ ] Calibrate boundary stress and effective area (including spatial nonuniformity); document whether integration is signed.
- [ ] State metric signature, coordinates, normalization, and a derivation connecting calibrated observables to each metric component.
- [ ] Propagate measurement/model uncertainties and preregister validation and falsification criteria.
- [ ] Add integration tests and a versioned calibration record before using outputs for scientific claims.

All boxes are intentionally open in this scaffold.
